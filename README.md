# Career & Performance Tracking System

## Project Overview

The Career & Performance Tracking System is an Excel-based project designed to demonstrate how Microsoft Excel can be used to organise activities, monitor progress, and measure performance.

The workbook brings weekly planning, daily activity tracking, job application management, and performance reporting together in one place.

This is a self-directed portfolio project developed to apply and demonstrate practical Excel skills.

## Tools & Skills Used

- Microsoft Excel
- Excel formulas and functions
- Data validation and dropdown lists
- Structured tables
- KPI calculations
- Dashboard design and data visualisation

## Key Features

### 1. Weekly Plan
Organises objectives and planned activities across five weeks to support structured planning and progress monitoring.

### 2. Daily Tracker
Records daily activities, expected outputs, completion status, and time spent. The day and week fields are calculated automatically.

### 3. Job Applications Tracker
Organises job opportunities, company details, eligibility information, application statuses, and follow-up dates.

### 4. Performance Dashboard
Provides an overview of key performance indicators, including:
- Completed activities
- Total activity hours
- Applications submitted
- Interviews and offers
- Activity status
- Weekly plan progress

## Project Objectives

- Demonstrate practical applications of Excel in personal and professional organisation.
- Use formulas to calculate and summarise activity data.
- Build a dashboard that makes progress easier to monitor.
- Explore how structured records can support better planning and decision-making.
